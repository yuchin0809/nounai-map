## 0. 先に読む要点

1. 日本の政府系データ(国土数値情報・e-Stat・国土地理院)は、どれも「政府標準利用規約」系で、商用利用可、出典を書く、加工したら加工したと書く、国が作ったように見せない、が基本。ただし国土数値情報はデータごとに条件が違う。
2. 地球地図日本のページ(GSI)には「国土地理院コンテンツ利用規約が適用される」とだけ書かれており、「非商用」とは書かれていなかった。1作目では「非商用・出典明記」と整理していたので、そのときの根拠(旧版の注意書き等)と食い違う。1作目の根拠を見直すこと。
3. GitHub Pages は静的サイト・広告課金なしなら規約上は問題なさそう。帯域は月100GBの「ソフト制限」。1回1MBなら月10万回の読み込みが目安。
4. 日替わり、URLハッシュ共有、画像生成、localStorage は全部サーバーなしでできる。ただし「全員の集計(みんなの割合)」はサーバーなしでは不可能。
5. 計測は GoatCounter が最有力(個人情報を集めない設計)。

## 2. GitHub Pages の制約

事実(公式):
- 公開サイトのサイズは 1GB 以下。ソース用リポジトリも推奨 1GB。
- 帯域は月 100GB の「ソフト制限」(ハード上限ではない)。
- ビルドは 1時間10回の「ソフト制限」(自分で書いたGitHub Actionsワークフローで公開する場合は対象外)。デプロイは10分でタイムアウト。
- 「オンラインビジネス・ECサイト・商用SaaSを動かす無料ホスティング」としての利用は不可。パスワードやクレジットカードなど機密性の高い取引にも使わない。
- 寄付ボタンやクラウドファンディングへのリンクは可(規約本文)。
- GitHubは、利用制限に反した場合にサブドメインを取り上げられることがある。
URL: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits / https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features

判断:
- 広告・課金を載せない無料ゲームは、規約の範囲内と読める【推測】。
- 広告(AdSenseなど)は「オンラインビジネスを運営する」に当たるかが規約の文言からは判定できず、グレー【推測】。課金・販売は明確に不可寄り。載せたくなったら、そのときに Cloudflare Pages など商用可のホスティングへ移る前提にしておくと安全。
- 既存調査(REPORT.md)にあった「Cloudflare」「Vercel Hobby は非商用限定」とも整合。

バズった場合の目安(計算根拠つき):
- 前提: 帯域のソフト制限 100GB/月 を 100,000MB として計算(GB=1000MBとした。1024MB換算なら約2%増えるだけ)。
- 1回の訪問が 1MB なら 100,000 ÷ 1 = 約10万回/月(1日あたり約3,300回)。
- 0.5MB なら 約20万回、2MB なら 約5万回、5MB なら 約2万回。
- 「訪問」1回に地図データ全部を毎回読む前提。ブラウザキャッシュ(2回目以降)は小さくなるので、実際はもう少し余裕がある【推測】。逆に、画像やフォントが重いと、ここで想定した1MBを簡単に超える。
- 「ソフト制限」を超えた場合に何が起きるか(警告、制限、停止)は、取得したページには書かれていない【不明】。GitHubからメールが来る、という運用が一般的と言われるが未確認。
- 対策: データは事前にJSON化・圧縮(gzipはGitHub Pagesが自動で行う【推測】)、地図は簡略化、フォントはサブセット化、画像はWebP。重くなったら Cloudflare(無料CDN)を前に置くか、静的ファイルだけ別ホストに移す。

法令面(日本):
- 電気通信事業法の「外部送信規律」(通知・公表等)は、対象となる電気通信役務(SNS・掲示板・検索・情報提供サービスなど)を提供する事業者に適用される。総務省の資料では、自社の情報提供用サイトは「電気通信事業」に当たらないと説明されているが、個人のブログやゲームが第三号事業に当たるかは判断が分かれうる【二次】。確定的な結論は出せず【不明】。
- 対策の方向性: 計測は GoatCounter のように個人情報を送らないものに限り、プライバシーポリシーのページに「何を計測し、何を集めないか」を1ページ書いておく【推測】。

## 5. 未成年(高校生)が運営する際の安全面

事実:
- GitHub は13歳以上が対象で、自分のアカウント上のコンテンツとその結果には自分が責任を負う(利用規約)。13歳以上の未成年についての追加規定は規約にない。居住国の法律を守る責任がある。
- 日本の成年年齢は18歳(2022年4月から)【一般知識・今回未確認】。課金・契約・広告収益を扱う段階では、保護者の同意や名義の整理が必要になる【推測】。
- 公開リポジトリには、コミットのメールアドレスと名前が残る【一般知識】。GitHubの「メールを非公開にする」設定(noreplyメール)を使う【一般知識・今回未確認】。
